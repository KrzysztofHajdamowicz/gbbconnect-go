# gbbconnect-go

Unofficial Home Assistant add-on that connects GbbOptimizer MQTT to Modbus
inverters using SolarmanV5, Modbus TCP, RTU-over-TCP, or a local serial port.

Configuration is managed in the add-on UI. Runtime state and incremental log
cursors are stored in the add-on's persistent `/data` volume.

See the **Documentation** tab for driver-specific settings and setup guidance.
